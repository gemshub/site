 A new version of GEM-Selektor is released, v3.12.2 [:octicons-arrow-right-24: download](../../start/gemselektor/download.md)

 This version comes with the [THEREDA](https://www.thereda.de) database (release 2026-01-r17) for saline systems with the Pitzer model. THEREDA can be selected directly when a new project is created. The library project TestTHERE has examples: salt concrete leached by brines, seawater evaporation, and solubility of salt systems compared with experimental data. How to start is on the [THEREDA page](../../community/thereda.md).

 The GEM2MT reactive transport module now has the same code as [xGEM2MT](https://github.com/gemshub/xgem2mt), with better progress reporting and error messages.
